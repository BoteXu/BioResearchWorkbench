# 分子生物学干实验

先明确研究问题、物种、组织/模型、独立生物学单位、比较方向与参考发布版。涉及基因组坐标时补充组装版本。先查当前 Biomni 状态与工具目录；历史成功、最近尝试与当前环境验证分开看，过期状态要重新验收。

用 `molecular_biology.guide_molecular_drylab` 选择适合问题的路线，按需阅读安装中的 MOLECULAR_DRYLAB.md。它生成计划，不执行候选方法。需要正式推断时先进行统计咨询，完成输入/设计/资源 QC，再通过已有服务器环境和共享 SSH 流程派发。大计算、大下载留在服务器；不在本地重复安装分析栈。

## 对结果作有边界的解释

- 剪接区分 exon event、transcript usage、abundance 和 structure；基因表达不足以支持异构体，RNA 不足以证明蛋白变化。检查 junction/全长证据、可映射性、覆盖、参考、测试全集和真正独立重复。delta-PSI 使用 fraction。
- 染色质/RNA 调控区分 motif、可及性、结合、空间接近和特异扰动。结合不自动给出正负调控方向，Ribo-seq 占据需要配对 RNA 和交互模型才能讨论翻译效率。
- 蛋白域/GO/PTM 绑定准确异构体、序列和残基，保留证据代码及 NOT。位点检测、结构预测和同源推断不自动成为功能验证。
- 分子互作区分功能、物理、pairwise direct binding 与复合体成员。保留检测方法、负结果、物种、片段/突变、复合体展开和原始文献。
- 扰动/筛选保留独立单位、匹配对照、特异性、混杂、效应与区间；条件特异效应不能直接外推成一般因果。此流程审查返回结果，不设计编辑试剂。
- 机制图逐条绑定主张与定位来源，核对参与者、方向和上下文；保留冲突、阴性和替代解释，不从多条相关性拼成因果链。

## 复用其他模块

表达/组学复用 omics-design，统计复用 statistical-plan，结构和对接复用 structure-review/docking-review，论文证据复用 claim-audit，代码与环境使用现有 code_review/code_execution，返回结果和不明提交使用 remote-compute。Zotero、私有索引、论文协作与交付仍按各自明确范围操作；不因启用本技能而读取全库或修改私人文献。

工具路线见 [tool-routing.md](references/tool-routing.md)。未连接的外部候选必须继续做选中代码、依赖、许可、权限和真实运行审查。复用已经工作的客户端，避免仅为了目录数量安装重复 skill/MCP。

## 完成判据

交付可定位来源、精确输入/参考/设计、实际执行与回执、QC 阻断、证据层级和未解决问题。工具检查成功、后端完成、参考结果一致和科学结论分别报告。私有草稿、配置、研究数据、路径、地址、结果和日志留在私有范围；只外发用户明确批准的公开标识/检索式。
