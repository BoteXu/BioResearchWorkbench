# CPA、scGPT、BoolNet、MaBoSS 实际调用源码审阅

本扩展现为 v1.1-private，12 条源码路线。新增 4 条均已实现实际后端调用与专用 QC/输出/衔接代码，科学运行 0/4；总体 0/12。所有示例都禁用且不包含真实数据、检查点、QC 或服务器结果。测试不证明软件在服务器可运行或科学正确。

| 方法 | 已落实的调用、QC 和结果 | 方法差异与服务器待验收 |
|---|---|---|
| CPA | 当前 CPA 类的 load/predict；遗传扰动训练/检查点/单位谱系、完整模型资产哈希、同轴 registered reference、X 层、剂量/组合/类别支持；配对 control 重建和 perturbation 预测，控制 RMSE 门槛；保存基因效应、供者覆盖、实际对比和推断诊断。 | 不调用历史 facebookresearch CPA 的不同 API。不把真实训练外未见类别、单扰动训练后的组合或超剂量支持当可靠预测。当前适配不支持注册在独立 layer 的模型。posterior samples 是精度参数，不是泛化验证；实测独立扰动、no-change/合理线性基线和原生同输入复现仍待服务器验收。 |
| scGPT | 实际 TransformerGenerator 全权重严格加载、原生 forward/perturbation flag；必须 perturbation-finetuned checkpoint 和冻结 vocab/config/基因序列；同尺度、同细胞类型与供者控制；对照/扰动解码差避免重建偏差，保存完整基因分母及控制 RMSE。 | 不是 generic pretrained scGPT 即能虚拟 KO。未用静默 partial load、未知基因 pad 替代或截断序列伪造覆盖。当前固定 deterministic decoder，explicit-zero Monte Carlo 路线未冒充已实现。实际 Torch/架构兼容、供者/靶基因留出及独立 perturb-seq 对照未验证。 |
| BoolNet | 实际 native loadNetwork/fixGenes/stateTransition；执行前只允许非可执行 Boolean grammar，拒绝 R 表达式/函数、未解析节点、非二元常量；完整加权 binary 初始状态、明确更新方式与预算、每步 KO clamp；同步周期活动与异步有限时域分开。 | 只支持本入口声明的 BooleanNetwork，不把 Symbolic/Probabilistic 模型混为一谈。同步未解析周期应失败；异步末态和随机轨迹不证明吸引子/稳态，更不是 RNA FC 或独立供者。需实机原生网络、已知固定点/周期和随机更新参考分布对照。 |
| MaBoSS | 实际 load/copy_and_mutate/Simulation.run 与 node/state trajectories；包和实际 MaBoSS 二进制固定；BND/CFG/速率审阅，完整独立 Bernoulli 初始概率；KO 初态归零及 OFF，目标输出强制保留验证归零；完整概率质量、范围、时间覆盖、native MC errors 和末步变化。 | 固定速率与初态假设下的连续时间随机逻辑模拟。当前入口明确是独立 Bernoulli 初态，不冒充有相关性的联合初态。有限末时点不自动叫渐近稳态，MC误差不叫生物 CI。实际二进制/API兼容、已知解析小网络、速率/时间/轨迹预算稳定性和实测现象对照未验证。 |

跨流程只准备 predicted-hypothesis 衔接，绑定实际源结果/上下文/源码/版本。RNA delta、嵌入/网络距离、逻辑概率、速度与代谢通量保持独立语义；逻辑/嵌入/速度结果不得自动变成 RNA 差异或实测证据。新的基因级通路流程需版本一致的已审核 ID 映射与新的 QC/计划。未知提交不得自动重试，不新增公开接口或 MCP 后台。

- [scGPT 原生扰动教程](https://scgpt.readthedocs.io/en/latest/tutorial_perturbation.html) 与 [TransformerGenerator 源码](https://scgpt.readthedocs.io/en/latest/_modules/scgpt/model/generation_model.html)。

不分发第三方源码、权重或数据库；不在本机执行科学分析，不安装本机科研依赖，不上传任何私有数据或配置。许可/来源和实际软件指纹必须在真实使用前按选定版本复核。

末轮 API 源码核对：CPA 每个组合成员分别序列化剂量，按已保存 setup_args 重新注册每个反事实查询，并校验实际 perturb/covariate encoder；使用真实 is_trained_ 标记。当前 X-only 遗传模型不支持 DEG-mask/化学 SMILES 的附加注册字段，遇到这些配置明确拒绝，不静默丢弃。scGPT 将 pad flag 固定为 2，与 0/1 扰动指示分开。MaBoSS 另外核对原生退出码、完整状态的数值/范围/时间轴、节点概率与 MC error 轴，保留 maximum_native_MC_error 数值和完整原生误差文件。
