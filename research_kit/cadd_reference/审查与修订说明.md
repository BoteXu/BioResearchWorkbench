# 分子对接、动力学与计算生物学规范 v3.1 私有修订

## 采用结论

父版本 v3.0 已有较完整的化学身份、结构准备、对照、独立运行、采样与统计、端点能量、自由能及增量复用框架。本轮采用“保留原流程、修正具体代码缺陷、补深方法合同”的方式，生成私有 v3.1。它可作为 Biomni 的规划、任务交接与返回摘要审查参考，不是经过真实分子/服务器验收的科学分析引擎。

审查材料为用户提供的 DOCX 和 137 文件工具包。原 DOCX 的保存页数属性为 1，不代表真实页数；修订稿由 Word 重新排版并更新目录引用。原文件、提取文本、来源清单和修改映射分别保留。

## 已修正的问题

1. **空科学证据可通过就绪检查。** 使用虚构文本复现了原 `quality/audit_project.py --ready` 在状态均写 passed、证据为 `[]` 时仍返回 metadata_ready。新版 project schema 2.1 要求非空的证据快照列表，每项含 path、sha256、bytes；检查实际文件及哈希。旧 2.0 仅作草稿检查，不能无迁移套用新版就绪模式。
2. **报告覆盖。** quality 与 environment 的报告改为独占创建；已存在的环境报告在版本探测之前拒绝，避免覆盖历史记录。
3. **软件身份检查不足。** 增量计划器递归拒绝嵌套的未知/空版本，显示已存在产物，并明确 run 是规划状态，不授权覆盖或派发。
4. **生成物谱系。** MD 输入生成器增加生成器、模板及实际输出哈希。修订过程中实际发现 Windows CRLF 与 LF 内容哈希不一致，已改为确定换行写入并重新通过双引擎文本生成测试。

全部修补仅作用于派生副本。哈希证据检查只证明所选择字节一致；passed 审查仍是调用者/研究者的判断，不能据此证明化学、力场或科学结论真实。

## SciSpace 与原始来源

SciSpace 检索了跨引擎转换、采样/独立重复和结合自由能三个通用问题，并为选定论文提取 limitations 辅助记录。仅通用方法词离开本机；私有文档、化合物/临床数据、路径、日志和结果未上传。工具返回中的作者、年份、附录 DOI、预印本与正式论文分别核对；自动 limitations 的未报告内容不代表没有限制。

本轮复核重点来源包括 [GROMACS 副本交换](https://manual.gromacs.org/current/reference-manual/algorithms/replica-exchange.html)、[PLUMED partial_tempering](https://www.plumed.org/doc-v2.10/user-doc/html/partial_tempering.html)、[ParmEd 拓扑接口](https://parmed.github.io/ParmEd/html/gromacs.html)、[自由能实践指南](https://livecomsjournal.org/index.php/livecoms/article/view/v2i1e18378)、[亲和力基准指南](https://livecomsjournal.org/index.php/livecoms/article/download/v4i1e1497/1399/5059)、[采样与不确定性指南](https://livecomsjournal.org/index.php/livecoms/article/view/v1i1e5067)及 [PoseBusters 检查](https://posebusters.readthedocs.io/en/latest/checks.html)。使用范围和 DOI 见 revision_sources.json。

最新 ff14SB/ff19SB 移植预印本作为检索线索保存，本轮未全面核验其完整实现与服务器安装，不据摘要直接引入力场。原手册的全部历史引用保留，但本轮没有声称已逐篇独立重审所有原始参考文献。

## 实际验证与边界

- 原 ZIP 的完整文件清单和校验值匹配；有界静态检查解析 10 个 Python 和 49 个原 JSON。扫描规则的大部分命中是文献 URL；人工核查了进程调用、文件读写及网络相关位置，没有在这 10 个 Python 中发现网络上传、安装或凭据读取例程。这不是全面安全保证。
- 修订副本的 **29 项元数据、文件操作和模板生成测试通过**，覆盖空证据、旧合同迁移、证据改动/范围逃逸、报告防覆盖、依赖环、软件身份、复用失效、并列排名与跨模型分数隔离。
- 科研输入只生成文本，未执行 Meeko/Vina、LEaP/grompp、Amber/GROMACS、轨迹分析或服务器作业；未安装新的科研依赖。
- 原 VALIDATION.md 是来源作者的历史记录。其所有测试没有原始回执/用例随包提供，本轮独立重现的范围以新回执为准。
- 文档保留原有正文（明确修订处除外）和外部链接，新增目录页码可更新；全册生成预览并作缩略检查，重点修订页单独检查。最终页数和版面结果见 qa/document_structure.private.json 与 visual_review.private.json。

## 日后使用

可要求：“按私有 CADD v3.1 规范规划/审查这个对接或动力学项目。”通过既有 docking-review/structure-review 的私有引用读取；选定研究问题、实际输入/设计、方法配置和真实服务器回执后再审核相应模块。

继续复用当前 Biomni cadd 工具；新增 module JSON 与其协议/摘要参数不是同一合同，不能直接互传。与私有转录组 v2.1.1 也保留独立 schema。此次规范接入不更改共享服务、注册、调度器或本地科研引擎的启用状态。

本版仅用于用户私有库与私有安装引用，未推送公开 GitHub，不进入公共发行包。
