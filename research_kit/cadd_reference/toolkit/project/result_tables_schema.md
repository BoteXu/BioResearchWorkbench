# 结果数据表的字段与粒度

数据可保存为 TSV、CSV、Parquet 或其他明确格式；这里规定信息粒度，不提供模拟结果。

## 逐帧观测量

每行是某一运行的某个时间点的一项观测量。字段包括 project_id、system_id、model_id、state_id、replicate_id、segment_id、frame_index、time_ps、metric_id、value、unit、selection_id、reference_id 和 source_path。分段拼接后仍可追溯原文件和帧号。缺失数据使用明确缺失值，不填零。

## 接触与氢键

逐帧表注明 partner_a、partner_b、残基和原子映射、定义和几何阈值。汇总表按运行给出有效分析帧数、观察时间、占有率和分块估计；间断接触寿命与连续接触寿命分开定义。未出现事件与文件缺失分别表示。

## 残基层面的结果

保留物种、chain、拓扑残基编号、原始结构编号、UniProt位置和共同对齐位置。对缺失或非共同区段使用缺失标记，不强行插入零值。计算 RMSF 差值、接触差异或分解能差值时记录对照及方向。

## 重复层级汇总

每行对应一个模型、状态、重复、分析窗口和指标。字段包括估计量、单位、保留帧数、时间范围、相关性处理、有效样本估计、分块大小、是否稳态、排除原因及来源。随后另建组间比较表，不丢弃重复层级后只保留所有帧混合的均值。

## 能量输出

逐运行保留受体与配体定义、拓扑和轨迹版本、PB/GB协议、能量分量、总估计、熵项是否纳入、单位、窗口及误差定义。不同物理模型或状态间不可比较的量分表保存。残基分解的分组和加和约定另列。

## 图源数据

每张图有 figure_id、数据路径、分析脚本版本、配置、排除规则、图例和创建日期。图中各点代表独立运行、时间块、分子还是供体，应在图例及数据字典中写明。轨迹帧的散点表示时间观测，样本量的定义应保留其相关性与重复层级。
