# I15 动态网络与变构及界面敏感性

版本 3.0.0

### 启用条件和结论范围

当普通接触与 RMSF 已提示远端协同变化，且研究目标涉及候选位点如何与功能区域关联、配体如何改变界面组织或不同状态的沟通路径时，启用本模块。动态网络将节点、接触与运动统计组织为图，可以识别候选耦合关系和路径；这些图模型并不自动建立细胞信号方向或因果机制。[IM31]

研究开始前定义源区域与目标区域，并保存其独立依据。不能先搜索所有节点对，再只展示最符合预期的一条路径。把网络指标作为可验证假设排序工具，与局部结构、化学可解释性及外部功能证据共同评估。

### 输入和节点映射

输入应包含可比的平衡轨迹、独立重复、统一参考对齐、残基及链/isoform 映射、功能区域、界面原子集合和图定义。每个节点至少有 `node_id`、`chain_id`、`sequence_position`、`structure_residue_id`、`representative_atom_or_group` 与 `component_type`。缺失残基、辅因子和配体如何进入网络要明确，不以矩阵下标代替生物学残基号。

分别冻结节点粒度、空间接触判据、时间占有率门槛、是否纳入序列相邻节点、相关度定义与边权转换。阈值用于构图，应评估邻近合理阈值下结果稳定性；没有适用于所有蛋白的统一距离或占有率阈值。

### 从轨迹到网络的步骤

1. 在合适的参考框架下移除整体运动，检查对齐是否把两个结构域真实相对运动混入或消除。对于不同问题，可比较全局与局部对齐的敏感性，但不能在同一对比中悄悄更换方式。
2. 按重复分别计算接触占有率和所选相关度。线性位移相关、距离相关与互信息不是同一物理量，不能互换名称；有限样本和共同慢漂移都可能产生表面相关。
3. 只在声明的接触图内建立加权边，并记录边权含义。若使用相关绝对值构造权重，正相关与负相关的符号信息已被压缩，应在原始相关图中另行保留。零相关、缺失和不接触需要不同处理，避免为不存在的边生成零成本捷径。
4. 分析社区、节点中心性、源—目标路径与多条备选路径，保存算法、随机种子和解析参数。WISP 的思想是分析较短的多条候选路径，而不是只依赖唯一最短路径；路径仍来自统计网络。[IM30]
5. 在重复与分块之间比较边和社区的稳定性，再形成状态差异。社区编号只是每次运行的标签，应按节点重叠等规则对齐后比较；相同编号不代表相同社区。

### 结合扰动响应与界面分析

如果需要进一步筛选可能影响整体运动的区域，可考虑基于协方差或弹性网络的扰动响应扫描。ProDy 提供相应方法及方向定义：矩阵条目应区分扰动节点与响应节点。[IM29] 这里的虚拟力或统计扰动不是实际氨基酸替换的等价物，不能直接给出某个突变的功能效应。

界面分析按同一残基映射输出接触占有率、盐桥/氢键、埋藏表面积、相对取向和组分间网络。不同预测复合物起点应作为模型分支比较；同一界面长期保持可能与起始构象和局部势垒有关，不能单独证明生理互作。

若比较不同实验条件、配体或已有变体，可先给出可重复的结构统计差别，再列为需要实验检验的候选耦合区域。网络中心性高并不必然等于特异性功能位点，结构核心、节点度和构图规则都可能影响排名。

### 稳健性验证和失败回退

最低验证包含独立重复、合理构图阈值变化、轨迹时间区间变化和节点映射检查。对于相关统计，随机打乱每帧会破坏时间结构；若用置换/替代数据做零模型，应说明保留与破坏哪些特征，并考虑块结构。输出不稳定时，首先定位是采样差异、对齐选择、阈值边缘效应还是网络算法非唯一性，不只延长同一条轨迹。

差异网络应区分新出现/消失的接触和已有接触强度改变；比较频率前说明分母是否一致。两条件各有 3 个独立重复时，统计单位仍是这些独立重复及其合理层次，不能用数万个边或帧增加生物学重复数。

### 可视化与可复用输出

`I15-P1` 为相关矩阵及残基映射；`I15-P2` 为重复间接触/边稳定性；`I15-P3` 为叠加在结构上的社区与多路径；`I15-P4` 为状态间差异网络；`I15-P5` 为扰动响应矩阵及方向标签；`I15-P6` 为界面接触和取向的多重复比较；`I15-P7` 为候选区域证据表。网络图布局、边宽和颜色要有固定意义，并保存原始节点/边表，避免视觉布局被解释为真实空间或时间顺序。

输出 `nodes.json`、`edges_by_replicate.json`、`network_definition.json`、`community_mapping.json`、`path_results.json` 与 `network_qc.json`。这些文件是推荐接口，不代表当前工具包已替用户计算网络。优先复用符合前处理条件的既有轨迹；新分析定义只触发重分析。新增轨迹要求更新相关统计、网络稳定性和图表；改变序列、化学态或物理模型则需独立采样并保留旧模型分支。
