# I05 命中证据升级与实验反馈标签

版本 3.0.0

### 触发条件和证据边界

首轮筛选结束后，若结果只有 hit=1，却无法判断它代表高分、检测信号、直接结合或细胞功能，启用本模块。它规定外部实验反馈的数据和解释接口，不替代实验室已有的具体测定规程。ChEMBL 区分 binding、functional、ADME、toxicity、physicochemical 等类型；靶点 confidence score 描述 assay-to-target 关联，而非某个活性值正确的概率。[IS11]

用两条轴登记状态。一轴是化学有效、对接适用性、位姿可解释、参数可行和模拟完成；另一轴是物质身份、相关测定信号、直接结合、功能、细胞内靶点相关证据、选择性和干扰审查。各项允许 unknown、pending、inconclusive、supported、contradicted 或 not_applicable，并保存理由。细胞有效而直接结合未知，或已结合但功能未显示，都是可以保留的真实状态。

结构警报是待澄清事项，不等同已证明假阳性。小分子聚集造成非特异抑制的原始研究说明，测定信号可能存在与预想靶点机制不同的解释。[IS12] 预算应围绕最关键的证据缺口安排，不能把所有冲突都交给再做一条 MD。

### 最少反馈字段和回流顺序

每条 observation 至少有 observation_id、parent_id、sample_or_lot_id、assay_id、target_construct、biological_context、endpoint、value、unit、relation、日期、重复层级、原始文件、拟合版本、QC、审核记录及可否用于训练。实物批次未知就标缺失，计算母体 ID 不能代替样品身份。

回流按五步执行：核对样品与模型结构；审查原始范围与测定 QC；核对单位和关系符号；按测定类型和条件分层；最后生成筛选或模型所需的派生标签。输出 label_version 和 transformation_log，保留原始观测以便重新派生。

浓度响应数据保留浓度、响应归一化依据、拟合模型、参数约束、区间和不确定性。观测没有覆盖可辨识的平台或主要转折时，不强迫输出精确 IC50，可按数据报告范围、方向或不可估计。拟合模型和是否可估计需要实际数据审查，本手册不预填任何曲线或活性值。

### 验收 晋级和失败回退

计算高分但身份不清，先核实身份；曲线反常或干扰证据明显，先区分检测问题；结合已确认但模式不明，安排能区分位点或状态的结构分析；同系列差异明确且模式可信，进入 I04 或 I06。每次追加计算写下其可能改变的决定，若无法回答，应暂缓投入。

未测、采购失败、溶解失败、无效测定和计算失败不能统称 inactive。同一母体的矛盾结果在解决前保存为分层或冲突记录。训练标签按事先约定规则生成，不只保留符合假说的观测。验收要求原始记录可追踪、分子身份一致、关系符号有效、重复层级明确且派生标签可重建。

### 输出 图形与增量条件

输出 evidence_matrix、observation_registry、label_derivation、conflict_log 和 next_question_queue。I05-P1 为候选×证据矩阵，颜色表示支持程度、符号表示来源和有效性；I05-P2 为真实浓度响应与拟合不确定性；I05-P3 为批次和重复点图；I05-P4 为不同检测原理的成对结果；I05-P5 为计算排名到后续证据的流向图。空白不等同否定，单一图形也不把证据自动升级为机制证明。

新实验只追加 observation，合法原始对接和轨迹可以保留；标签汇总、优先级、训练集、校准和下一轮决策需要更新。若实物与模型身份不同，创建正确映射并标记旧计算不适用，不能仅改名称继续复用。历史决策与当时可见证据保持不变。
