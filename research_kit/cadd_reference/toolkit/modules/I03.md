# I03 跨靶点选择性与反筛证据矩阵

版本 3.0.0

### 触发条件与面板定义

首轮得到候选后，若需区分家族成员、识别可能解释相同表型的其他靶点，或安排反筛证据，启用本模块。选择性面板明确物种、蛋白成员、结构域、剪接体、突变、状态和终点。激酶原始大面板研究展示了复杂的跨靶点相互作用模式，支持以明确面板描述选择性。[IS05] 不将历史药物结果当作新候选的现有证据。

FGFR 类问题先区分胞外配体相互作用、完整受体信号和胞内激酶口袋。胞内口袋对接优先级不能证明模拟胞外生长因子的作用；该区别写入 project_question 和 endpoint_definition。

### 输入和成对评价

输入 panel_targets.json、panel_structures、candidate_parent_states.sdf、target_specific_controls.json 和 assay_panel.json。target_state_id 绑定序列、构建体、结构、口袋、质子化和共因子。候选在目标及反靶点使用可追溯的状态政策；对目标枚举更多状态时，不能隐藏其额外搜索机会。

按问题把面板分为近缘成员、机制备选靶点和项目相关离靶点，每个成员说明加入理由。先对各靶点独立完成方法验证，再建立 compound×target×receptor_state 任务表；失败、未运行与不适用分别保留。对优先候选补相互作用指纹及口袋比较，只有会影响选择性判断的成对体系再安排 MD。

### 评分和选择性口径

跨靶点相减 Vina 或 CNN 裸分仅是该协议下的计算差值，不能称为 ΔΔG 或选择性倍数。每靶点内部百分位也是相对于其参照集合的位置；参照库不同，两个百分位仍不等价。比较前固定参照库、计数单位及每靶点验证；足够实测数据才支持相应校准与外部评价。

若有同一条件下的实测 Kd，S=Kd,off/Kd,on，ΔpKd=pKd,on−pKd,off=log10(S)。单位先统一。若 on=0.1 μM、off>10 μM，则 S>100，不能写为 S=100；这只是删失口径示例。不同构建体、终点或检测条件不可直接拼成精确比值。

### 验收与冲突处理

检查每靶点的对照、适用性、失败比例和状态覆盖。目标成功而反靶点任务失败的候选没有计算选择性证据。对接与实测冲突时审查结构、状态、位点和机制，不能删除不符合模型的实测值。MD 可比较模式与相互作用的不确定性；一条反靶点轨迹脱离不能量化选择性，接触占有率比值也不是 Kd 比值。

先做最有区分力的小面板，再由结果决定是否扩展。预算优先解决与主假设直接竞争的解释，避免把所有数据库关联对象都安排长 MD。面板未覆盖的对象保留未知，不据此声称广谱选择性。

### 输出 图形与增量

输出 target_panel_manifest、panel_run_status、panel_score_table、panel_evidence、selectivity_bounds 和 next_evidence_priority。I03-P1 为候选×靶点矩阵，实测与计算分面；I03-P2 为口袋及等价残基叠合；I03-P3 为相互作用条码；I03-P4 为可比实测 ΔpKd 的区间森林图；I03-P5 为面板覆盖。未测、失败、不适用和有效检测范围内无效应使用不同符号。

结论写成“在该面板与条件下的选择性证据”。新增靶点只需完成新靶点及其对照，旧合法原始计算可保留；面板汇总和依赖全体面板的统计更新。改变一个靶点的口袋、状态或模型，仅使该靶点相关计算与依赖结论失效，不自动重算其他靶点。
