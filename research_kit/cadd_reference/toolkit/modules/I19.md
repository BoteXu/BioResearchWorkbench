# I19 扰动表达与药物重定位

版本 3.0.0

### 什么时候值得加入

当已有可靠疾病或处理签名，并希望寻找能产生相反表达模式的小分子，或希望判断一个候选药物是否与已知机制相似时加入。本模块把表达证据作为与结构筛选平行的候选生成渠道；产物是 `query_signature.tsv`、`reference_context.tsv`、`connectivity_results.tsv` 和 `repurposing_decision.tsv`。它不要求先把每种药物指定为某一个直接结合靶点。

### 最小输入与可比较单位

疾病签名包含稳定基因 ID、方向、效应、排序统计量、来源细胞类型、对照定义、供体数和纳入规则。参考签名包含化合物母体和化学状态 ID、扰动类型、细胞系、剂量及单位、时间、重复、质量指标、数据库构建版本和 signature ID。相同化合物在不同细胞或时间产生的结果是不同上下文，不能按药名无条件平均。

L1000 Connectivity Map 将扰动表达模式用于连接化合物、基因扰动与疾病签名；其评分包括不同含义的统计量，τ 是相对于参考背景的标准化连接强度，不是疗效概率。[IB12] 具体查询需按使用的数据构建和接口区分原始 connectivity、标准化分数、τ 与显著性，避免把不同输出混成一个尺度。[IB13]

### 运行步骤与对照

1. 从供体层面分析形成查询签名，明确疾病减对照的方向；保留上调与下调列表及完整排序。对细胞组成主导的 bulk 签名，先做组成敏感性或使用相关细胞类型的签名，减少把减少某类细胞误解为恢复该细胞功能。
2. 记录与参考基因空间的交集、缺失比例和 ID 映射。查询覆盖不足时停止给出强排序；不能将缺失基因补零后视为无变化。
3. 先用预先选定的签名规则运行，再做有限的稳健性检查，如不同合理签名大小、剔除一般增殖或应激主导部分、不同独立疾病队列。应将主分析与探索性改变分开登记。
4. 在细胞、剂量和时间层面读取结果，再按预先规定规则形成化合物层摘要。展示正负方向不一致的上下文，不能只保留最负的一条签名。
5. 设置签名方向翻转、匹配基因集大小的随机查询、已知方向对照或外部疾病签名等检查，判断结果是否依赖非常普遍的应激模式。随机对照应保留合理表达/检测背景，而非从完全不可检测的基因中抽样。
6. 对候选核查细胞存活、细胞周期、广泛转录抑制等解释。有负连接但伴随强细胞损伤，并不等价于有用的病理逆转。对用于疾病治疗的方向性陈述，还需要与疾病阶段及代偿机制相一致的证据。
7. 将表达候选与已知药理、直接靶点资料、靶点表达和结构可行性并列。对接到某一靶点可以提出新的作用假说，不能自动解释数据库中整张转录签名。
8. 输出优先级及下一步可区分的验证问题，例如“是否在相关细胞中重现预定方向的通路读出”“该效应是否与细胞损伤分离”“是否存在靶点参与证据”。

### 验收与失败回退

结果至少在独立疾病签名或合理签名规则下保持可解释的方向，且主要贡献基因可审阅；不能只有一个未经质控的细胞系条件。若参考库没有相近细胞背景，结果可以保留为外部线索，但降低迁移性判断。若同一候选在不同条件下方向相反，记录交互作用与上下文，不强行投票成单一正负。若候选由广泛毒性或增殖抑制驱动，回退到更接近疾病机制的查询和终点，而不是通过删去反对数据制造一致性。

### 可视化与增量接入

`I19-P1 上下文连接热图`：行是化合物，列是细胞与时间/剂量组合，颜色用同一种明确评分，缺失用独立样式。`I19-P2 签名方向与核心基因图`：展示疾病效应和扰动效应在同一 ID 下的方向及覆盖，避免由低覆盖几条基因主导。`I19-P3 稳健性排名图`：横向比较主签名、独立队列和预设敏感性分析，保留不一致者。

新增疾病供体后可以复用冻结参考签名，但须重建查询及其统计；新药物或新实验签名可以仅追加查询任务，旧 raw connectivity 在背景完全相同时可复用。若 τ、百分位或 FDR 依赖全库背景，库扩展后这些归一化与多重检验值应重算。疾病签名方向或细胞定义改变时，旧结果是另一假说的结果，不覆盖。计算预算以查询数、参考上下文数和置换/重采样数估计，先做小规模覆盖和方向检查，再扩大候选检索。
