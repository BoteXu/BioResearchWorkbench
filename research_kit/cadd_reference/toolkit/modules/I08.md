# I08 新化合物与新标签接入后的筛选重算

版本 3.0.0

### 触发事件与科学依赖

通用文件哈希判断字节变化，科学增量层判断影响哪些结论。新增 500 个化合物不一定重跑旧库；修改所有配体的质子化政策也不能只重跑文件名新增者。本模块把变更分类，再交给增量规划器。配套规划和排名比较脚本用于检查与汇总；它们不自动判断分子化学是否正确。

可复用任务绑定 parent、state、conformer、receptor_state、位点或查询、软件与模型版本、参数、种子、原子映射和相关内容。软件路径相同不保证版本相同，文件名不变不保证内容不变。旧任务还必须成功且通过该阶段必要审查。

### 变更到重算范围

| 变更事件 | 原始计算可保留部分 | 必须更新的派生结果 |
|---|---|---|
| 新增母体 | 旧输入和协议一致的任务 | 库统计 失败分母 排名与选择 |
| 新增供应记录 | 已计算的相同状态和构象 | 来源 可获得性 实物对应 |
| 新增受体构象 | 旧受体的有效任务 | 新任务 集合聚合 稳健性 |
| 修正结构或手性 | 其他母体的有效任务 | 该母体全部相关计算 |
| 修改状态或口袋政策 | 可证明不受影响的任务 | 受影响任务与依赖聚合 |
| 新增或修订标签 | 合法原始对接和轨迹 | 标签 模型 校准 评价 决策 |
| 仅修改图形样式 | 数值与科学分析 | 图文件与图版本 |

保留不等于混用。更新评分器后旧结果可以用于历史分析，但同一正式排名需要一致协议或经过相应评价的校准。旧库使用 A、新库使用 B 的分数不能悄悄放在同一列比较。

### 接入一批数据的操作

第一步建立 delta_manifest，记录 added、modified、removed、relabelled 和 metadata_only；退出候选池不删除历史。第二步用标准化结构与既定立体政策匹配已有 parent，保留来源别名，不只靠名称。第三步比较状态、构象和任务语义身份。第四步输出 reuse、recompute、new、blocked 及理由。第五步只执行输入和审查齐备的新任务。第六步合并有效结果与失败记录，按冻结政策更新报告。

协议修订需要桥接集合，在同一对象上比较搜索、姿态、打分和准备的变化。桥接用于诊断，不自动证明协议可交换。若策略更新由旧评价结果驱动，下一版本需要新的前瞻或独立证据。

### 排名变化的两种来源

在共同候选、相同协议下比较旧排名，回答旧结果是否改变；在完整新池中比较入选名单，回答新增对象改变了什么。两个问题分别画图。Top K 的 Jaccard 为交集大小除以并集大小，说明集合、K、并列规则与有效样本不足时的处理。秩相关只用可比较的共同对象，不能给失败任务补零排名。

全库百分位、全库 Z 分数及全库聚类依赖整体数据，即便原始得分不变也可能因新增对象而改变，所以要更新。若需要固定参照分布，则冻结参照版本。枚举更多状态后最优分数变好可能来自更多搜索机会，报告状态数和模式支持，不自动称更强结合。

### 验收 交付与图形

输出 delta_manifest、reuse_decisions、new_task_plan、bridge_validation、ranking_delta、candidate_status_history 和 updated_figure_manifest。验收包含母体与状态数量守恒、全部结果有来源、未把 blocked 或 failed 当阴性、历史未覆盖、排名协议可解释。无法解释的变化先隔离对应分支，其他合法分支可继续。

I08-P1 为新增及复用任务数；I08-P2 为变更影响依赖图；I08-P3 为共同候选排名迁移；I08-P4 为新候选进入流向；I08-P5 为图表过期状态；I08-P6 为有效成本与新增信息。节省任务数须按同一定义统计；节省墙钟时间需要真实运行记录，不能仅按文件数量宣称。

优先预算用于受影响且会改变决定的分支。最终报告同时说明新增什么、复用什么、为何可复用、哪些结论因新证据改变。这样既避免无效重跑，也避免用过期结论解释新数据。
