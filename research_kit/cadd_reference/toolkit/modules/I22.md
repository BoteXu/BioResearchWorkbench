# I22 图形复用与交互浏览及实验反馈

版本 3.0.0

### 可交付图形的最小单位

将每张科学图定义为“图源数据、图形规范、生成代码、软件版本和解释边界”的组合，而不是一个 PNG。输出 `figure_registry.json`、`figure_data`、`figure_specs`、`figure_scripts`、三维会话和静态导出。图注册表至少有 `figure_id`、`question`、`data_id`、`data_sha256`、`analysis_id`、`unit_of_analysis`、`filters`、`transform`、`units`、`uncertainty_definition`、`color_mapping`、`limits`、`created_from_release` 和 `caption`。

图形的最少统计身份随数据层级改变：筛选用母体、化学状态或位姿；模拟用模型、独立重复、片段、时间和原帧；组学用供体、样本、切片和细胞。一个联动看板可以同时展示这些层级，但不可以把“选中的点数”统一显示成实验样本量。

### 从二维表到三维和组学的联动

1. 为候选建立稳定的链接键：`parent_id → state_id → pose_id → model_id → replicate_id → frame_id`；为生物学建立 `gene_id → transcript_id → protein_form_id → residue_map_id`。多对多关系存独立关系表，不在一张宽表中复制成看似独立的结果。
2. 从候选点进入详情，第一屏显示实际证据类型、原始单位、失败状态和适用背景；再进入三维位姿、重复轨迹或供体效应。不让颜色或汇总总分掩盖未完成和失败任务。
3. 从 MD 接触热图选择残基时，同时显示所用的拓扑残基编号、蛋白参考编号、原子选择和阈值；从时间点进入原帧时使用原始索引映射，避免按处理后帧序号误取原始轨迹。
4. 三维结构保存相机、对齐选择、表示、颜色、可见对象和模型标识。Mol* 支持保存状态与会话，状态文件可能仅链接原始输入，归档时须确认数据是否嵌入及外部依赖是否仍可访问。[IB19] 对需要长期复现的项目，至少同时保留本地结构和会话引用表。
5. 网络图保留节点/边属性、样式和会话，不能仅导出屏幕截图。Cytoscape 可保存网络、属性和视图状态，但数据表里的边来源及方向含义仍由项目负责维护。[IB20]
6. 所有交互筛选产生可导出的 `view_state.json`：记录选中的候选、系统、样本、过滤器和尺度。重新打开时先校验数据版本，若源数据已更新，提示该视图来自哪个发布版本。

### 静态图和交互图各自承担的任务

静态图用于稿件和审阅，保留固定数据快照、明确坐标和完整图注；交互图用于查找异常、追踪来源和比较条件。结构动画应注明播放的是哪条轨迹、时间缩放、抽帧间隔、拟合方式以及是否省略水和离子。若动画为了展示剪辑不同重复，应在转场时明确标注，不能让观众误以为是一条连续动力学过程。

每种图定义共同尺度和自动尺度两种模式。发表图通常锁定同类面板的坐标与色标，探索视图允许缩放，但导出时必须保存限值。P 值显示截断、不可估计值、阈值外数据和删失观测都有单独标识。把 `failed`、`not_run`、`filtered` 和 `missing` 统一染灰会破坏决策含义，应至少在详情和数量审计中保留四者区别。

### 实验反馈怎样进入计算循环

为每个被选择的候选创建 `decision_id`，记录当时的数据截止时间、模型版本、选择理由、预测和拟验证的问题。实验返回时新增 `measurement_id`，保存分析物身份、条件、批次、技术与生物重复、原始结果、拟合模型、删失符号和 QC 状态。先核对身份和终点，再判定是否能与原预测比较。

将结果分成四种工作状态：可比较且支持、可比较且相反、测定失败、上下文不匹配。测定失败不是阴性；上下文不匹配也不能简单算预测错误。相反结果应触发对化学身份、暴露、靶点参与、模型状态及评分适用性的诊断，保留失败假说记录。只有在标签处理规则冻结后，才把新数据纳入下轮 QSAR 或主动学习训练。

若同一候选已经用来调模型或挑参数，其实验结果不能再次作为完全独立测试集。新增数据的划分按项目的时间、化学系列、供体或独立批次目标预先确定。跨轮报告累计测试数、独立命中数、失败数和不确定数，不能只用“本轮挑中者”作为分母掩盖历史失败。

### 验收与增量可视化

`I22-P1 数据谱系图`显示某一图源自哪些原始文件、分析和模型版本；只展示真实依赖。`I22-P2 发布差异图`比较新旧版本新增候选、证据变化、排名变化和缺失恢复，将“原始分数改变”和“排名因库扩大改变”分开。`I22-P3 预测与反馈配对图`显示预测时点与真实返回终点，按独立母体或真实重复统计，并保留删失与失败。

图形验收包括 ID 链能定位到真实文件，筛选分母可重算，单位和误差定义存在，原始数据变更会触发对应图失效，以及导出 PNG/SVG 与交互视图的固定状态一致。改配色只重画图；改接触阈值重算相关分析和图；改原子映射必须重审受影响轨迹分析；改分子身份则向更上游传播。预算先保留完整可审计表和静态图，再为需要反复查阅的层级做交互联动，不为每个常规指标搭建独立平台。
