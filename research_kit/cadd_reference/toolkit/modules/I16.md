# I16 靶点证据与生物学实体对齐

版本 3.0.0

### 何时加入及本模块的产物

当项目已经能得到对接排名，却还不能说明“为什么选择这个靶点、这个组织中的这个蛋白形式”时，先加入本模块。它也适用于新公开队列、新遗传学证据、数据库更新或新实验结果进入项目后的证据重排。最终交付三张可追溯表：`entity_map.tsv` 统一实体，`target_evidence.tsv` 记录每条证据，`hypothesis_register.tsv` 记录值得进入结构计算的具体假说。数据库综合分只用于定位证据，不能直接转为靶点治疗成功概率。

本章及后续增量模块的字段、文件名和验收关卡是本规范提出的工程约定；引用用于支持方法机制和数据资源的适用范围。Open Targets 将证据映射到 Ensembl 基因和疾病本体，并保留来源及证据类型，适合作为索引入口；最终判断仍要回到原始记录、研究设计与实际生物学对象。[IB01]

### 最少输入及身份字段

每个候选至少有 `target_id`、`species_taxon`、`gene_id_version`、`gene_symbol`、`disease_or_phenotype_id`、`tissue`、`cell_type`、`intended_direction`、`source_release`。方向可以是抑制、激活、补充、阻断特定互作或未知，未知必须保留，不能从差异表达上升自动推导“需要抑制”。进入结构分支还需要 `transcript_id_version`、`protein_accession_isoform`、`sequence_sha256`、`construct_range`、`maturation_state` 和 `structure_id_chain`。

`target_evidence.tsv` 按“一个原始研究中一个可解释的终点”存行，包含 `evidence_id`、`study_id`、`cohort_id`、`sample_overlap_group`、`evidence_class`、`measured_entity`、`intervention_or_exposure`、`outcome`、`effect`、`effect_unit`、`uncertainty`、`context`、`direction`、`source_url`、`limitations`。同一队列进入两个数据库时保留两个来源链接，但生物学证据计数只算一次。不能把文献篇数等同独立证据数。

### 实际工作顺序

1. 固定物种、疾病表型、拟研究组织和问题方向，先排除名称相近但对象不同的条目。以稳定 ID 为连接键，基因符号用于显示。Ensembl 的基因、转录本和蛋白版本变化有不同含义，蛋白版本会随肽链序列变化而改变；因此不要全表删除版本后就声称实体完全一致。[IB02]
2. 按人遗传学、疾病组学、表达可及性、干预实验、直接互作、药理学与结构可行性分别收集。对遗传学证据保留等位基因、性状、组织和候选基因定位依据；对组学证据保留方向及供体层级；对干预证据保留作用方式与所测终点。
3. 建立重复来源关系。记录同一研究的 PMID、数据 accession、样本集合和后续再分析，避免一个数据集被文献挖掘、表达数据库和网络数据库重复加权。
4. 核对序列和蛋白加工。UniProt 中展示的序列可能是前体，信号肽、前肽或转运肽切除会改变实验中的成熟形式；把前体编号、成熟链编号和模拟链编号分别保存。[IB03]
5. 把结论写成可检验陈述，例如“特定细胞群中受体异构体 A 可检测，候选配体可能通过其已知口袋改变某一读出”。同时写出至少一个竞争解释，如细胞组成变化、一般细胞应激或另一靶点作用。
6. 用门槛和证据矩阵形成优先级。门槛可以是身份可核实、对象可获得、实验读出可区分等；统计量、结构分数、模型置信度保留原尺度。若需要综合权重，必须展示权重敏感性和缺失信息，不能把自定权重表述为经过验证的成功率模型。

### 验收及失败回退

实体表中的一对多映射需要人工处理结果，禁止任意取第一行；成熟链和构建体边界必须与实验描述相符；每条“支持”都能定位到原始研究，且清楚说明支持的是表达、相关、互作还是干预。若目标只有基因级表达而无异构体信息，暂时保留多个蛋白形式的假说，不能静默选最长序列。Ensembl Canonical 是代表性转录本，不保证在研究组织中占优势。[IB04]

无法确定作用方向时可以推进探索性结构可行性，但报告中必须保持方向未知。批次与疾病完全混杂的表达研究只支持描述，不升级为可靠疾病效应。若组织中相关蛋白形式尚无证据，优先补证据，而不是不断加大对接规模。

### 可视化及结论边界

`I16-P1 证据来源矩阵`：行是候选假说，列为证据类别，格内显示支持、相反、缺失或不适用；链接到 `evidence_id`。`I16-P2 研究级森林图`：仅把可比较终点的效应及误差放在共同尺度，分开不同物种、组织和干预方式。`I16-P3 实体映射图`：展示基因、转录本、蛋白形式、构建体和结构之间的可核实连线，缺失或歧义用明确标记。

这三类图分别回答证据是否齐全、效果是否跨研究一致、计算对象是否对应真实对象。任何一张图都不能单独证明直接结合或因果机制。交互浏览时点击证据格应显示原始终点及限制，不能只显示最终颜色。

### 计算成本与增量规则

先完成候选级 ID 对齐和文献去重，再下载大矩阵；这通常比先做全数据库网络更能限制无效工作。只新增一条研究时，保留未改变的结构和 MD 结果，更新证据矩阵和排序。若新证据改变蛋白序列、成熟链、异构体或需模拟的实际状态，应向下游结构准备、对接、参数化及相应分析传播失效；仅改变作用方向假说时，先重审解释与所需模型，不自动作废相同物理模型的原始轨迹。仅修改基因显示名称，不应使未变的原子体系重算。保留旧版本假说和撤回原因，不能删去曾经相反的证据。
