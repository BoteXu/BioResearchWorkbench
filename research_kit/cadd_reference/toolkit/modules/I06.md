# I06 相对自由能候选网络与预算决策

版本 3.0.0

### 适用问题与交接范围

有一组可比较类似物，位点和关键状态已有依据，需要分辨其相对结合趋势时启用。这里决定分子对、网络、预算及结果回流，具体 Amber 或 GROMACS 炼金设置由相应 MD 模块承担。OpenFE 官方教程展示 ligand network 和结合及溶液支路的组织，可参考其数据模型；它的执行栈不等于自动转为 Amber 或 GROMACS。[IS13]

若主要不确定性仍是配体身份、位姿、共价或配位机制、主要质子化状态，先处理这些问题。结构相似只意味着映射可能容易，不保证自由能假设成立。

### 节点 边与执行顺序

节点包括 parent_id、state_id、bound_model_id、化学图、净电荷、立体信息、参数版本和实验参考。每条有向 edge_id 保存 A、B、共同原子映射、变换方向、变化的元素与键、净电荷变化、环或手性变化、受体状态、两条热力学支路、重复安排和审核。

1. 基于化学和模式可比性生成允许边，人工核查映射，不只接受最高自动映射分数。
2. 建立连通分量，明确孤立节点。树形网络成本较低，但没有内部回路闭合检查；在关键排序或高不确定区域增设诊断路径，并说明其价值。
3. 优先安排能改变候选决定的边。核心、环、净电荷和模式同时变化时，考虑合适中间体、拆分问题或换方法，不为图上连通而接受不合理转化。
4. 每条边先审查采样与数值诊断，再进行网络推断。相空间重叠、重复、估计器和误差是炼金分析的核心问题。[IS14]
5. 将通过的边与其不确定性送入全网分析，保留被拒绝边和原因。闭合残差小不证明物理模型正确；共同误差可能抵消。残差大时定位边、状态和采样，不仅靠拟合平滑。

状态必须显式登记。固定一种质子化态的计算结果，不能在没有相应处理时当作多状态混合的实验总亲和力。跨净电荷等情况进入专门协议审查，普通中性系列的设置不能自动套用。

### 方向 单位与验收

固定 ΔΔG(B−A)=ΔGbind(B)−ΔGbind(A)。同温度和标准态下，适用的实验 Kd 满足 ΔΔG(B−A)=−RT ln(10)×[pKd(B)−pKd(A)]。B 的 pKd 更大时，B−A 更负。300 K 时一个 pKd 单位约对应 1.37 kcal/mol；这是换算关系，不是方法精度保证。

先比较边差，再决定是否使用实验锚点估计节点值。锚点误差和共同偏移应可见；任意设零的相对结果不能直接报告绝对 Kd。验收同时关注映射、两支路完整性、模型一致性、重复及方法要求的采样诊断，不能以程序正常退出或误差栏很小代替。

### 成本 输出 图形与增量

预算对边、支路、重复和状态求和，先用代表边测性能及诊断，困难边预留额外资源。正式任务表分开记录资源上限和科学停止条件；后者不是文件写满。

输出 edge_registry、mapping_review、network.graphml、edge_diagnostics、edge_results、network_inference 和 decision_delta。I06-P1 为带方向和状态的网络；I06-P2 为边不确定性；I06-P3 为回路残差；I06-P4 为重复一致性；I06-P5 为实验与预测 ΔΔG；I06-P6 为候选排序区间。共享节点或数据引入的相关性要进入误差传播，不能把全网边当完全独立样本。

新增类似物且旧物理模型不变时，只算连接新节点所需边及预定诊断边，再更新网络。旧节点状态、参数或受体模型改变，使相关边失效并影响全网推断。新实验通常只更新验证和标定；若它揭示模型身份错误，再沿依赖关系重建计算。
