# I10 受体构象与动态口袋及隐蔽口袋

版本 3.0.0

### 启用条件与问题拆分

当单一受体构象不能解释已知配体、口袋开合控制进入、不同实验结构给出不同位点，或希望探索传统结构中未充分暴露的位点时，启用本模块。首先区分四个问题：有没有几何空腔、空腔是否在所研究状态下可访问、是否能容纳并稳定结合化合物，以及结合是否影响功能。几何口袋分数只覆盖其中部分条件。隐蔽口袋研究说明瞬态空腔及其与功能位点的耦合可以从动态集合中探索，但预测结果仍需相应验证。[IM05][IM06][IM07]

### 输入与构象身份

输入包括原始结构集合、序列和残基对应关系、apo 或配体状态、缺失区与模型可信度、膜/糖链/伙伴遮挡信息，以及可用轨迹的系统 ID、重复 ID、平衡区间和权重来源。每个抽取构象登记 `receptor_conformer_id`、`parent_system_id`、`trajectory_hash`、`frame_index`、`time` 和 `selection_method`。

不能沿用软件在不同帧产生的 `pocket_1` 作为同一个生物学口袋。建立 `pocket_id` 映射表，依据残基集合、空间重叠、入口位置和局部结构对应关系跟踪口袋。不同链编号、isoform 或缺失插入段先解决映射，再比较口袋大小。

### 从已有轨迹获得受体集合

先选与问题有关的局部特征，如口袋主链与侧链二面角、关键残基距离、门控接触及口袋体积；全蛋白 RMSD 可能被远离位点的柔性区域主导。对各重复采用相同特征定义，在可比空间聚类，再选真实帧作为代表。保留簇占有率、来源重复和时间分布，检查某一簇是否只来自最初松弛阶段。

聚类不是为了固定获得某个簇数。应比较候选簇数或距离阈值能否区分功能相关口袋状态，同时避免把近重复快照展开成大量受体。普通、已平衡且可比的采样可以估计特定模型下的占有率；自适应采样或有偏轨迹不能直接按帧数当平衡权重。受体占有率也不能自动作为 docking 分数的加权系数。

初次输出可限定为少量结构差异明显、质量合格的代表，先在已知对照上检查它们是否提供新增信息。若新增构象只使所有配体得到更低的极值分数，而对照区分、位姿有效性和重复稳定性没有改善，应检查多重搜索和极值选择偏倚。

### 口袋探测与跟踪步骤

1. 在保留必要成分的结构副本上进行静态口袋探测，保存工具版本、全部参数、输入校验值及原始输出。fpocket 可用于静态空腔探测，mdpocket 可分析结构集合中的口袋分布与描述符；实施时核对当前版本的选定口袋和输入格式。[IM05]
2. 将探测结果转换为项目级 `pocket_catalog`，保留体积、极性/疏水组成、埋藏程度、入口、邻接残基及遮挡备注。不要将不同算法的分数混成一列。
3. 在统一参考系中跟踪候选口袋，输出 `pocket_timeseries`，同时标记算法未识别、口袋被遮挡、结构缺失和真正关闭；这几种状态不统一填为零。
4. 为开口、半开口、关闭等状态制定可复查判据，绘制各重复的状态时间线。检查口袋体积变化是否伴随局部不合理展开或整个结构失稳。
5. 对入选构象分别建立对接准备和局部 box，使用相同父化合物集合与对照验证。跨构象比较保留受体来源，避免仅保留所有构象中最优的一个分数。

如果采用机器学习预测隐蔽位点，登记预测模型版本、输入结构来源及训练/测试独立性可得信息，保留预测置信度定义。预测图用于选择待查区域，不能给出未采样的开口概率或结合自由能。[IM07]

### 增强探索与反馈

常规采样未见开口时，先判定需要的是没有证据还是证实关闭。短时间未观察到事件通常不足以支持后者。可把多个实验构象或合理代表作为新的采样起点，或转入 I14 讨论具有明确变量和验证方案的增强采样。若用混合溶剂或探针模拟探索热点，应单列探针组成、浓度和模型，检查其是否诱导非生理的局部展开；这类占有图不能直接当作纯水体系平衡占有率。

探索结果回写 `receptor_panel_version`。新构象进入筛选前需再次完成结构质量和已知对照验证。发现新的高分口袋并不自动触发全库重算，先用小型验证集合评估新增信息，再决定是否增量筛选该构象。

### 图形 验收与预算

`I10-P1` 为口袋体积与门控距离的多重复时间线；`I10-P2` 为口袋出现频率或空间密度等值面，注明是普通采样、有偏样本还是重加权估计；`I10-P3` 为口袋残基接触与构象状态矩阵；`I10-P4` 为受体构象与对照配体的位姿/富集表现；`I10-P5` 为候选位点证据分层图。固定等值阈值和视角后比较不同条件，保存视图脚本与分析表。

最低验收包括口袋身份在构象间能对齐、开放不是结构破坏产物、主要口袋状态有来源记录、对照可评估。若某状态只出现一次，输出候选结构及不确定性，不报告可信平衡概率。口袋描述符计算常比新增 MD 便宜，应先复用已有完整轨迹；内存和文件量则按抽帧数与原子数估算。

新增受体构象通常只新增该构象的准备和对接任务。改变口袋定义会使描述符与 box 失效；改变蛋白序列、装配体、化学状态或遮挡组分会使相关物理模型失效。原来不同口袋的结果可保留，不能因候选集合更新而覆盖原始证据。
