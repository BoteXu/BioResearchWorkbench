# 验证范围与使用边界

版本 3.0，2026-10-24。

本交付由方法手册、数据与决策模板、少量辅助脚本以及待适配的模拟输入组成。以下检查针对文件完整性、算术、失败处理和展示，不代表已对用户的分子或硬件完成计算验证。

## 已完成的检查

|---|---|---|
| Python 与 JSON | 所有交付 Python 语法解析、全部 JSON 解析 | 语法与序列化有效，不等于科学模型有效 |

## 版本 3 新增检查

增量规划器和排名比较器使用独立合成文本与任意整数记录完成 20 项回归检查，涵盖分支失效、输出及证据改动、旧审查拒绝、绑定后待审状态、依赖/路径拒绝、目标依赖闭包、并列名次、共同成员相关性和跨模型比较。新绘图入口已实际生成 PNG/SVG 并目视检查。合成输入与图不纳入交付研究数据。

旧审查不能再次验收已改变的输出、日志或科学证据；只有输入指纹和精确文件快照均匹配时才可记录 accepted。审查意见本身仍由研究者负责。本包不是多用户调度或事务数据库，状态须串行更新。

28 个模块 JSON 是数据契约模板，已检查可解析、模块身份与空观测状态；它们不是自动科学验收器。原有未变的辅助脚本沿用已完成的验证，新增文稿与图形定义检查了引用、模块及图形 ID。主文档渲染后逐页检查，未改正文通过像素对应复用上一版的视觉检查。

## 实际项目还需要完成的工作

- 填写结构、化学状态、电荷、原子/残基映射、选择、路径、版本和研究设计。
- 检查参数、缺项、力场/水/离子匹配与科学适用性。
- 在实际安装环境核对命令与预处理，用代表体系完成最小化、短程运行和重启。
- 完成当前靶点的方法验证、实际筛选及全部失败记录。
- 按独立运行或生物样本层级评价采样、误差、敏感性与结论范围。

`--ready` 仅表示登记和证据文件符合脚本规则，研究者填写的审查记录不是脚本独立验证的科学结论。生成的输入仍需预处理审查；文件成功写出不代表引擎或物理模型验收通过。

正文中的搜索投入、时长、重复数、配额和预算均注明用途，不是统一合格阈值。绘图输入示例不含虚构观测值，须填写实际数据；公式图只呈现公式。使用时保存输入校验值、运行日志、修改记录、科学决定、失败与排除原因。
