# BioResearchWorkbench 私有深入整合 v3

本次补入上轮剩余的 71 条分析路线的服务器科学源码，保留原 v1/v2 与用户源文件。此版本只采用到本机私有库，不进入公开仓库、公开 CI 或公开发行包。

## 当前状态

- 71/71 已有具体分析分支、类型/尺度约束、输入 QC、结果角色、诊断、参数敏感性与返回检查代码。实际方法和原候选软件分开列出。
- 0/71 完成服务器科学实测。全部明确标记 `NOT_RUN_SERVER_UNAVAILABLE`。本机测试仅覆盖语法、计划、绑定、拒绝和小型伪造结果格式；没有拟合模型或运行组学、分子和训练计算。
- 现有其他标准流程、模型训练、CADD、序列/MSA/AF3 仍保留；本轮没有重新启动 MCP、修改共享服务、安装本地分析环境或下载数据库/权重。

完整清单见 [71 项逐项实现](71项逐项实现与验收.md)，逐项机器状态见 [验收台账](server_acceptance71.tsv)。科学核心位于 server/analysis71.R、native71.py、cell71.py、cli71.py，服务器共用执行层为 analysis71.py；不是只转发任意用户脚本的接口。

## 科学与工程边界

一些分支选用本轮明确命名的替代实现。例如：RNA-CNV 是参考归一化的染色体平滑，不声称为 inferCNV/CopyKAT；空间域为邻域增强 PCA/k-means，不声称为 BANKSY；固定区域甲基化模型不声称完成 de novo DMR 发现；GRN 为 motif 限制 ridge 和独立供者留出，不声称为 SCENIC+；PRS 为 PLINK2 固定权重及连续结局留出校准，不声称实现 PRSice/LDpred2 训练；PTM 为同一样本 site−protein 的显式调整，不声称为 MSstatsPTM。

细胞、spot、基因、肽段和克隆读数不能自动充当独立供者。CellRank/velocity/轨迹、空间置换、ORF 周期性和网络零模型输出保留条件性解释；不能由代码运行推断因果机制、细胞真实命运、DNA 拷贝改变或药效。共定位 ABF 路线保留单因果信号假设；多信号问题需先分解或选择现有专用路线。基于标注的 isoform 后果不等于实验证明的功能后果。

## 调用

先从 `examples71/<analysis_id>.project.template.private.json` 选择分支，补齐真实文件、完整哈希、科学参数和接受标准。模板所有缺失字段明确写 REQUIRED，不可当作成功示例。`context` 需要物种、构建、参考版本、尺度、独立单位、估计目标、专用科学决定及真实上游 QC；上游的观测文件必须由实际完成回执登记，观测数值不能仅由调用者填写 passed。

本地仅准备：

```text
<已有工具 Python> workbench.py plan --request <已审核项目配置> --out <全新服务器任务包目录>
<已有工具 Python> workbench.py workflow71-plan --root <选定项目目录> --request <逐阶段 DAG 配置>
```

这两步都不提交任务。准备文件默认 `server_execution_authorized: false`，不能直接在本机运行 server 目录。已有服务器就绪后，核对当前计算节点、已有软件与资源分配，再按原共享 SSH 流程明确派发。缺依赖时停止并报告，代码没有自动安装逻辑；未知提交不重试，失败保留部分文件与日志。

返回时选取有界摘要，使用 `workbench.py accept`；必须选回四项专用结果、QC、实际数值诊断、所有敏感性汇总及版本记录。大矩阵、H5AD、数据库和完整轨迹继续留在服务器，仅保留其已登记的哈希。结果数值阈值要写到 `analysis_diagnostics` 的实际字段，如 `0.metrics.converged`，附定义、单位和依据。

## 跨流程衔接

`workflow71.py` 验证有向依赖、独立单位和明确输入转换；`server/handoff71.py` 在已有服务器上真正物化下一阶段输入，保留来源回执、人工科学审阅、转换源码与输出哈希。固定转换包括 LIANA→独立供者 LR 对比、Scirpy→克隆/表型与多样性、fgsea→leading edge 和经审核的一对一标识转换；相同语义的输入可显式 identity 传递。复杂关系不得靠改列名冒充可互换数据，未有转换的组合需提供已审核的精确下游输入。

handoff 要求工程返回检查通过、审核者明确接受指定的下一用途、物种/构建/单位/参考上下文一致。它只生成下一阶段输入，仍需重新 QC、生成新计划与派发。既有 cross_domain.py 继续维护转录/蛋白/isoform→结构/CADD 的标识与证据边界，绝不把 RNA 变化直接解释成结合活性。
