# 71 项逐项方法源码复核记录（私有）

审阅覆盖 71/71；这是对声明实现范围的方法、QC、输出与衔接的源码复核，不是科学运行验收。所有服务器科学实测仍为 0/71，NOT_RUN_SERVER_UNAVAILABLE。原版/来源规范保留，新旧方法与结果角色变化需重新生成计划。

每项具体判断如下。完整输入 QC、结果角色、源码位置/哈希与验收边界见同目录 JSON/TSV。

| 分析 | 逐项方法判断、修复与替代差异 |
|---|---|
| apa_usage | DRIMSeq 已定量 poly(A) 位点用量；内引物/末端覆盖 QC 移到拟合前，补全 gene/feature 过滤与 stageR。不是从 reads 开始的 QAPA/DaPars，也不自动鉴定新位点。 |
| bulk_cnv | CNVkit call 接收已分段 log2 和实际 VCF；参考性别、偏差审阅、等位状态和纯度/倍性点分开。网格点不是估计出的后验最优解，也不包括 reads 到分段。 |
| bulk_deconvolution | 实际 MuSiC 供者参考，修复 reference gene names，检查共享基因及每类参考供者；原生拟合保存。重建残差是可用参考下的代理诊断，不是成分真值或绝对细胞数。 |
| camera_sets | 实际 limma CAMERA 竞争性基因集检验；删除常量特征、保留真实背景；voom 输入必须带同轴精度权重。与 ORA/GSEA 的零假设不同。 |
| cell_fraction_contrasts | 独立单位计数分母、logit 或 asin-sqrt 后 limma 对比；补 transformation 选择。不是 scCODA 多项层级模型或 propeller 完全复现；参考、零值与组成依赖需实际敏感性。 |
| clonal_phylogeny | 实际 PyClone-VI 拟合及 CCF/簇分配不确定性；<=8 完整 clone 的 sum-rule 树穷举检查环和所有候选，并限制完整搜索预算。候选兼容树不是唯一已知进化谱系，样本不是独立肿瘤重复。 |
| clonotype_phenotype | 每供者 clone×state 的细胞标签置换，保留完整 null；未分配 clone 被显式排除，单 clone/state 不可检验。条件关联不等于供者总体或克隆因果状态效应。 |
| colocalization | 实际 coloc.abf 与新增 coloc.susie 多信号分支；共享变异覆盖、定量 SD/病例比例、已对齐等位基因、signed LD、收敛和 H0–H4 概率质量分别检查。无可信集合对是未评估，不能当作不共定位。 |
| cross_study_meta | metafor 随机效应、完整重叠对与 estimand 一致性、异质性及 leave-one-out。当前独立研究路线不接受未经建模的样本重叠；REML/DL tau 选择不等于解决人群差异。 |
| differential_binding | 实际 edgeR QL peak counts；固定共识峰、库分母、设计/对比与计数尺度。不是把已有强度当原始 counts，也不实现从 BAM 建峰的 DiffBind 全流程。 |
| differential_coexpression | Pearson Fisher-Z 与 Spearman centered donor bootstrap 明确分支；检查组内变异、完美相关、有效重采样分母。小样本近似/重尾校准未验证，边关联不能认定调控重连因果。 |
| enhancer_grn | motif 限制的 ridge 持出预测；训练特征缩放和 bootstrap 原尺度系数、真实持出 RMSE/单位分开保存。修复结果角色名；不是 SCENIC+ eRegulon，也不把预测准确率当调控因果。 |
| exon_usage | 实际 DEXSeq full/reduced exon 模型与原生 perGeneQValue；修复 featureID 及四角色语义。exon bin 的独立/重叠定义仍需真实输入 QC，不能将其当完整异构体切换。 |
| fate_probabilities | 实际 CellRank velocity kernel/GPCCA，要求来源一致的 donor-restricted graph 与明确终末状态，检查概率行和。概率是模型条件吸收概率，不是实测命运或独立细胞重复。 |
| fine_mapping | 实际 susieR RSS，固定变异/等位/LD 轴、对称/对角/特征值与收敛检查；PIP、可信集合和 ELBO 独立保留。LD 祖源/样本来源和 causal 信号模型不能由矩阵 QC 证明。 |
| footprinting | 实际 TOBIAS ATACorrect→ScoreBigwig→BINDetect；修复 fp-min/fp-max，BAM/FASTA 显式索引和参考长度 QC。BigWig 缺失区间仍未评估，足迹不等于直接结合实验。 |
| gsva_scores | 实际当前 GSVA 参数对象、基因集覆盖和正规设计/对比；分数矩阵与效应分开。GSVA 不是生化活性实测；基因集版本/背景和样本尺度需要绑定。 |
| hic_compartments | 实际 cooltools balanced cis eigenvectors 和指定 phasing track；完整掩码保留，reference 不覆盖时不判 switch。E1 符号需相位锚定，单 contact map 不是生物重复。 |
| hic_loops_tads | 实际 cooltools dots 的 lambda_bin_fdr 及 insulation windows，平衡/expected/坐标分辨率先检查。dots 与 TAD 边界是不同算法输出；空 loops 合法但不表示染色质无互作。 |
| impulse_response | 实际 limma natural-spline 模型，补显式 contrast、时间×组与曲线/覆盖正确角色。名字不代表 ImpulseDE2 或强制单峰 impulse 函数；输出为条件样条模型。 |
| isoform_switch | DRIMSeq+stageR 后按 delta_usage/显著性配对上升和下降 isoform，补结构域增减、CDS/NMD 差异，未知注释保留未评估。不是 IsoformSwitchAnalyzeR 全部功能后果；配对可多解。 |
| junction_events | 实际 junction cluster beta-binomial，补完整 event 定义/样本分母、数值 Hessian 正定与 gradient 检查；保留 LRT、delta usage 和区间。不是 rMATS/MAJIQ reads 级模型，小样本 LRT 校准待实测。 |
| kinase_activity | 实际 decoupleR ULM，先按同样本 total-protein 调整磷酸位点；映射和完整 regulator×sample 活动轴检查。ULM 估计不是酶动力学，不能把缺失活动填零。 |
| kinetic_velocity | 实际 scVelo dynamical；原始 spliced/unspliced、过滤、donor 内邻居及 Ms/Mu、拟合 likelihood 和原生对象分开。跨供者共用基因动力学仍是条件假设，不是已知轨迹真值。 |
| leading_edge | leading-edge 成员集合的 Jaccard 连通分量与代表项；补去重/全 term 背景和无显著项合法空结果。它是富集冗余概括，不是新的显著性检验或通路机制证明。 |
| ligand_target_links | 实际 NicheNet ligand activity，接收完整 receiver 可测基因背景和实际 prior；ligand/receptor/target 覆盖明确。prior 推断不是通信因果；数据库/参考改变需要新 QC。 |
| lipid_chain_patterns | 先每独立样本/类估计碳链和不饱和度斜率，再做明确 Welch/配对/HC3 对比；避免把脂质条目当重复。不是 empirical-Bayes lipidr 链交互模型，类内链特征混杂需拒绝。 |
| lipid_class_enrichment | 实际 fgsea 脂质类别集合；唯一脂质身份、类别映射与完整统计量背景。不是泛化为所有脂质通路的 lipidr 复现，身份歧义不能任意聚合。 |
| longitudinal_effects | 实际 limma duplicateCorrelation+样条/组交互，重复单位必须存在，设计秩与 residual df 检查；补真实 contrast 和正确角色。共有相关结构不能替代任意随机斜率模型。 |
| lr_consensus | 实际逐 donor LIANA rank aggregate，局部资源/复合体亚基/完整细胞群覆盖，额外输出统一线性均值乘积分数。共识 rank 用于同一次候选排序，不能跨 donor 当丰度差异。 |
| lr_differential | 输入统一 log1p(LR 线性均值乘积) 分数，拒绝 1-rank 对比；显式 Welch/配对/HC3，固定 LR 家族、缺失不填零。不是 limma moderated t，也不建立信号传递效应。 |
| methylation_gene_links | 预定义区域 M 值对比与 RNA 条件关联，BED 半开边界、覆盖和独立/配对单位；配对关联用 donor 内变化。不是 DMRcate/bsseq 新 DMR 搜索，关联不能认定甲基化因果。 |
| microbe_differential | 实际 ANCOMBC2 原始计数、固定分类/零值和 covariate 公式；显式 structural-zero taxon 标识。结构零、未检验和非显著分开，不把相对丰度当原始 reads。 |
| microbe_diversity | vegan alpha 与相对组成 Bray 距离、PERMANOVA/离散度检查；修复原始深度影响。当前独立单位分组路线不是任意重复/纵向设计；位置与离散度解释分开。 |
| microbe_gene_context | 实际离线 eggNOG-mapper 蛋白序列注释，完整 query denominator/数据库哈希和未注释项。功能是同源注释，不能认定样本实际功能活性；不下载重复数据库。 |
| microbe_network | 实际 SPIEC-EASI MB+StARS，补 getOptMerge 边选择频率，系数单独保留；路径边界须扩展，null 与稳定性分开。稀疏关联不是生物相互作用或因果网络。 |
| microbe_pathways | HUMAnN stratified 与 unstratified 分开，UNMAPPED/UNINTEGRATED 不进入 CLR 参考，独立样本正式对比。伪计数和可测功能背景是组成模型假设，不是绝对代谢通量。 |
| microbe_strain | 实际 StrainPhlAn 本地 marker/数据库，leaf-profile 交叉表、gap/marker覆盖和完整单位对应。缺失叶或序列不是阴性，树相近不能单独证明传播。 |
| motif_deviation | 实际 chromVAR GC 背景/匹配对象/峰顺序与 GRanges 坐标，deviation、对比和背景分别保存。motif deviation 不是 TF 结合/活性实测；相似 motif 身份需审阅。 |
| motif_enrichment | GC/长度匹配背景后的 motif Fisher，全 searched motif universe 包括零命中假设，保留匹配分母。它不是分层 CMH 或 de novo motif discovery；匹配不消除所有序列偏差。 |
| multiomics_mediation | 实际连续 mediator/outcome lm+mediate 与 medsens，独立完整单位、对比支撑/秩/df先检查。仅线性无交互范围；sequential ignorability 未被检验证明，不自动称因果机制。 |
| network_diffusion | 实际 weighted personalized PageRank，种子、持出、完整节点/边、null 保存。当前 seed null 为均匀位置置换，未冒充 degree-matched；优先级不是靶点因果或外部预测验证。 |
| peak_gene_links | donor/covariate 残差相关，boot 中重新拟合 nuisance；候选距离/完整峰基因映射和原尺度分开。条件相关不是增强子因果，不能当 Cicero/ArchR 标准实现。 |
| physical_ppi | 显式来源/证据类型物理互作图，正权重、无反向重复、自环与完整节点检查，保留 rejected edges。STRING 功能关联不能冒充物理实验互作；图 null 只检验拓扑。 |
| polygenic_score | 实际锁定 PLINK2 pfile/变异/等位/score sums，验证使用变异与非缺失 allele数；独立训练测试、基线与 endpoint 分支。祖源可迁移性/发现样本重叠不能由哈希证明。 |
| ppi_modules | 实际 Louvain、degree-preserving null 和边 bootstrap；重复抽边合并权重而非覆写。模块编号不可直接跨运行比较；模块是图划分，非已实验证实功能单元。 |
| protein_complexes | 复合体成员 mean-log abundance 后真实 limma，完整覆盖/成员效应保留。该聚合是丰度 proxy，不是 MSstats 或复合体化学计量/装配状态。 |
| proteogenomic_links | 按样本/搜索类别做带 ties 的 target-decoy PSM 与 best-peptide FDR，唯一变异肽映射和多肽支持，完整未接受项保留。肽段/PSM 控制不等于 variant/protein 层 FDR，不能宣布变异功能。 |
| ptm_adjustment | 同样本位点 log2−蛋白 log2 的真实 limma，对应关系/total protein 分母/不确定性明确。不是绝对 occupancy 或酶活测量；多蛋白映射需拒绝。 |
| rare_variant_burden | 实际 SKAT、burden、SKAT-O，修正 method=SKAT 的非法参数；MAF/MAC、minor-allele dosage、无亲缘单位、真实 null calibration和失败 mask 分母保留。不是 relatedness-aware 混合模型。 |
| repertoire_clonotypes | 实际 Scirpy nt identity，按 donor 定义、chain QC/条形码交叉表保存；未分配 clone 保持缺失。不是 AA similarity 聚类；不得跨 donor 复用同名 clone。 |
| repertoire_diversity | 按 donor 汇总 Shannon/Simpson/扩增及无放回 rarefaction，修复 NaN 巨型克隆，保留分配分母。rarefaction 区间是有限库抽样变动，不是生物总体 CI。 |
| scenic_regulons | 实际 pySCENIC GRN→CTX→AUCell，冻结本地 motif/ranking数据库；先排除持出 donor 再抽训练集合，记录真实训练单位。AUCell 不是 TF 活性实测；donor子集改变不是外部验证。 |
| signature_matching | 离线 signed rank/Spearman connectivity，完整 shared-gene/样本模型/剂量/时长背景和基因置换 null。条件基因标签 null 依赖交换性，不产生 donor 级药效或因果反转证据。 |
| singlecell_abundance | 实际 miloR neighborhood NB，donor sample顺序、设计/对比/offset及显式 neighborhood_id，SpatialFDR 与普通 FDR 分开。邻域/细胞数不构成独立重复。 |
| singlecell_cnv | 正常参考 RNA log2、染色体平滑、DNA segment 条件对照；参考/基因/半开边界与未覆盖区域检查。不是 inferCNV/CopyKAT，RNA 轮廓不能单独确定克隆、绝对 CN 或肿瘤身份。 |
| spatial_deconvolution | 实际 spacexr RCTD 现代/legacy API 分支；命名 cell-type factor、权重方向/行和/拒绝点/参考 donor 排除，保存原生拟合。legacy当前仅 full；参考重跑不冒充后验 CI。 |
| spatial_domains | 邻域增强 PCA+kmeans 的显式原生替代，section/unit/坐标、histology ARI和特征子采样 ARI。不是 BayesSpace 或 Leiden；条件重采样不代表完整空间/供者不确定性。 |
| spatial_gradients | section 内径向 spline、空间 block bootstrap 与 residual Moran I；边界/距离单位和完整 resample 分母。不是 iid spot OLS总体推断，block交换性和尺度需实际审核。 |
| spatial_lr | 固定 source/target细胞类型、monomer LR表达和半径邻居；在section、解剖块和类型内置换，低覆盖未评估保留。不是完整复合体 LIANA/COMMOT 模型，近邻表达不等于信号因果。 |
| spatial_niches | section/解剖 block 内标签置换的邻域富集，距离与单位映射明确。不是任意标签全切片洗牌；空间交换性仍是条件假设，spot不作为独立动物。 |
| spatial_variable_genes | 实际 SPARK-X 每section raw P，完整gene×section族统一BH，独立unit覆盖描述单独。跨section的conditional信号重复不是总体重复检验。 |
| ssgsea_scores | 实际 GSVA ssGSEA 参数对象、normalize设定、完整基因集覆盖及显式设计对比。不是自写 ssGSEA 近似；分数不等于通路绝对活性。 |
| temporal_modules | nuisance/时间组交互的 spline+KMeans 条件曲线；新加 rank/df、donor bootstrap设计退化和有效分母记录。不是 ImpulseDE2/STEM；模块稳定性是条件描述，不是新显著性证据。 |
| tf_activity | 实际 decoupleR ULM，边/目标覆盖和完整 regulator×sample 活动轴，之后真实 limma 对比。活动 proxy 与直接酶学/结合证据不同；缺失模型不能经 xtabs填零。 |
| trajectory_dynamics | 实际 tradeSeq 条件 GAM，raw count/pseudotime/curve weights轴、离线age NA处理、收敛比例和 predictSmooth 曲线。拓扑固定的不确定性未自动传播，细胞不是 donor重复。 |
| trajectory_topology | 实际根锁定 Slingshot、曲线权重和 donor子集重建；新增边 Jaccard，根保留/谱系数不再冒充边稳定性。嵌入方向与生物根需独立依据，不是真实谱系追踪。 |
| transcript_usage | 实际 DRIMSeq 过滤、design/contrast、feature/gene p 与 stageR层级控制、可解释 delta_usage，零分母不填0。不是差异表达或已证实 splicing机制。 |
| translation_efficiency | 实际 edgeR Ribo×RNA interaction，sample/unit/assay配对、同组/库分母和真实periodicity QC。必须区分 RNA改变与翻译交互，assay归一化假设仍需实测诊断。 |
| two_sample_mr | 实际离线 TwoSampleMR harmonisation、F统计、完整原始 instrument audit、action 2/3以及敏感性。LD独立/排除限制/方向和样本重叠不能由有效回执证明；不自动作治疗因果建议。 |
| uorf_translation | exon-aware P-site坐标、offset/已知CDS周期QC、uORF边界和分样本分母；分开条件read级binomial与新增独立unit对照sign-test，后者需完整匹配阴性ORF、单位/覆盖/ties分母。候选仅为周期性，不是 RiboCode/RiboTaper 或已确认翻译。 |
