# 教学流程整合 v3.3 私有工作草稿

商业软件按用户要求排除，仍只保存在私有库。本稿不代表“全部工具已完成整合”，也不替换当前 v3.2 稳定入口。

本稿沿用 315 页课件/315 单元对应讲稿的已绑定来源和 43 阶段工作图。新增 49 个固定服务器调用分支，其中 47 个为有范围限定的分析/模型分支，另有原生格式交换和回执绑定的表达谱衔接；另补 ML 流程中的实际 SHAP 计算选项。它们有实际软件调用、输入检查和返回结果检查代码，不能把“已写代码”读成“服务器已经验收”。

覆盖补强：Seurat/Harmony/SingleR、muscat/hdWGCNA、Palantir/Monocle3；cell2location/DestVI、BANKSY/SPARK/Squidpy/PASTE/Baysor/SpatialGlue；MSstats/XCMS/DIABLO/SNF；VEP/LDSC/SMR/HEIDI/IGV；原生 R nestedcv、SHAP；scGen、CellOT 检查点预测、biolord、scVIDR、CINEMA-OT、CellCap、CausCell；DiffDock、DiffSBDD、原版 RFdiffusion 骨架采样、MACE 分子单点；ProteinTalks、PRESCIENT、BATCHIE 后验。原 71 项注册表及既有私有扰动扩展保留。

逐项范围、差异与尚缺分支以 `native_tool_catalog.json` 和 `原生工具调用与输入输出_v3_3.md` 为准。所有新增分支均已关联到教学阶段，但阶段映射并不是实际执行记录。

本轮修复包括：重复角色结果不再只检查最后一份；明确选择验收文件；空标准输出不再被当作缺失结果；格式交换写回核对；模型子解释器的真实依赖另行绑定；DiffDock 默认配置覆盖参数的风险；BATCHIE 旧实现的全局随机流；CausCell 概念编码、标识丢失及空末批次；生成/重建与观测值、内部时间刻度与物理时间标签、模型置信度与亲和力的区分。低支持和缺失状态保留。

本地有 167 项契约/拒绝/回归检查通过；66 个 Python 文件完成语法解析、7 个 R 文件仅做语法解析。未在本机运行科研分析/训练/分子计算，未安装科研依赖。本轮服务器运行次数为 0；当前服务器连接也未探测。尚不能把这些检查称为科学方法或真实后端验收。

尚未完成原生接入的具名工具有 12 个：MAGPIE, DIA-NN, SIRIUS, CSI:FingerID, GNPS, DOCKovalent, MorphDiff, PRnet, scDiffusion, Squidiff, CellNavi, Stack。Amber 开放组件的原生引擎路径仍有缺口，商业 Amber 组件排除。gnomAD 复用已有 Biomni 客户端，不重复建立数据库客户端。本次没有复核完全部栅格图片中的额外软件名称，因此 87 个显式名称也不能称为课件全部图片工具的穷尽清单。

使用时先按实际研究填写被禁用的契约模板、实际版本/输入哈希/独立单位/QC/统计计划/结果阈值；`workbench.py plan` 只生成服务器提交材料。实际派发仍走既有共享终端；之后按真实完成回执选择返回摘要检查。只有原生方法、真实输入、实际软件环境及结果全部分别核对后，才能确认某项实际分析的验收。

原 PPT/Word、旧 ZIP、v3.1.1 基线和 v3.2 稳定源码均保留。此工作草稿未发布、未冻结、未修改共享服务或 MCP 注册。生产草稿包不包含原作者源文件、模型权重、研究数据、测试缓存或本轮运行日志；公开来源只纳入 URL/哈希等审阅元数据。
