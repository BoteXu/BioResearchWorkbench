# 整合深度审查：发现、修复与未验证层

审查对象：私有 integration v1 以及其采用的转录组 v2.1.1、CADD v3.1。审查日期：2026-10-25。

1. **深度不足确实存在。** v1 的 adoption 明确是 metadata_orchestration_only；35 项测试没有运行科学引擎。不能把 28/81/65/34 的目录和字段覆盖描述成完整科学能力。
2. **QC→分析缺少强连接。** v2 新增实际矩阵 QC 和结构/化学 QC，正式 R 分析需相同输入及实际 QC 运行产物；对接需受体/QC/准备谱系；pseudobulk 需对应细胞 QC 决定。源码和真实数值验收仍需服务器完成。
3. **结果审查过于依赖状态字符串。** v2 读取实际选回表和诊断：预测概率、fold 单位交集、真实观察值、姿势检查、轨迹时间、AF3 样本轴及收敛警告；缺失诊断或未知观测保留 HOLD。
4. **机器学习没有训练后端。** v2 增加实际训练与输出代码，区分预测、潜变量和图模型。27 个选择的可运行性都仍需对应软件环境实测；不是 27 个独立临床验证模型。
5. **跨域 ID 有值不等于匹配正确。** 新增选定映射表检查、异构体和物种/版本限制、源文件绑定、共享队列分组、observed/predicted/imputed 区分；不会由表达方向推断活性或结合。
6. **结构查询与生成混在一起的风险。** 已区分公开 AFDB 现有模型检索与已有服务器 AF3 生成。后者有实际引擎调用代码，完整保留 seeds/samples、置信度轴和结构来源；本轮没有运行。
7. **默认推断的风险。** RNA 双细胞模型不用于不支持的 assay；不自动改数据尺度、补缺失、裁掉失败状态、选择最佳 P 值或把原子/token/residue 轴互换。
8. **条件性分析不能靠一个通用模型冒充。** 完整契约目录保留，未落实为本轮原生科学代码的分支明确要求既有服务器专用后端。特别是复杂因果、物理资格和增强采样，不能以本地字段检查结案。

实施层新增：23 类科学入口（内含 6 个 R 方法），独立序列/AF3 输入与 provenance 检查，有界实际返回验收，以及服务器合成验收脚本。源码在本轮只做静态审阅和拒绝/返回逻辑测试，尚未完成真实 scientific backend acceptance。

接下来实测的优先顺序：matrix_qc 正/负设计 → sklearn 嵌套训练 → DESeq2/limma → 单细胞/聚合 → WGCNA/MOFA → 结构与 PoseBusters/Vina → 轨迹/热力学/删失模型 → 现有 AF3 安装。每步用独立真实回执，不自动重试未知提交。服务器未就绪时，保持该状态，不转到本机运行。

9. **MSA 获取与配对不能只留格式入口。** 新增真实服务器本地数据库检索、已有工具比对、query-coordinate A3M 转换、覆盖/去重/有效深度、显式配对和 AF3 数据阶段。官方文档复核发现手工行配对必须与 native pairedMsa 区分，已落实为输入/开关约束。
