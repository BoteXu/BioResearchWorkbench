# 方法与接口来源及核对范围

本轮只向公开检索发送通用方法/软件问题，没有私人文本、主机、路径、序列、变异、结果或账户数据。现有私有规范保持原归属，第三方算法仍归原作者；本包不分发第三方代码、数据库或权重。

- [DESeq2 官方 vignette](https://www.bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html)：参考原始计数、设计、对比和完全混杂的要求；具体服务器包版本须另验收。
- [scikit-learn 分组交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)及[嵌套验证示例](https://scikit-learn.org/1.7/auto_examples/model_selection/plot_nested_cross_validation_iris.html)：支撑训练内预处理/选择、分组和独立测试的分工。
- [TOTALVI 官方 API](https://docs.scvi-tools.org/en/stable/api/reference/scvi.model.TOTALVI.html)：RNA/ADT 原始计数、同细胞映射和 setup_anndata。MULTIVI 当前 API 已改为 MuData；本包没有把 TOTALVI 接口套给 MULTIVI。
- [WGCNA 作者资料](https://edo98811.github.io/WGCNA_official_documentation/)：网络构建与独立 preservation 分支；模块与 hub 不建立因果。
- [MOFA2 作者资料](https://biofam.github.io/MOFA2/)：显式视图与样本轴，缺失与因子解释；新安装/自动下载不在本轮范围。
- [PoseBusters 检查与 API](https://posebusters.readthedocs.io/en/latest/api.html)：实际化学/姿势检查；具体版本返回列需要服务器实测。
- [MDAnalysis RMSD 文档](https://docs.mdanalysis.org/1.1.1/documentation_pages/analysis/rms.html)：PBC whole-molecule 与对齐前提。参考页面版本较旧，实际安装版本和拓扑/时间/单位需独立核对。
- [AF3 官方输入](https://github.com/google-deepmind/alphafold3/blob/main/docs/input.md)、[输出](https://github.com/google-deepmind/alphafold3/blob/main/docs/output.md)、[引擎参数](https://github.com/google-deepmind/alphafold3/blob/main/run_alphafold.py)：核对原生 dialect、seed/sample、diffusion sample 参数、输出文件和 chain_pair_iptm 轴。官方页面存在版本描述未完全同步的地方，因此绑定具体已安装源码与 schema，不猜测服务器支持最新版本。

以上是对接口与方法边界的核对，不是所有算法的系统文献综述或性能排名。新科学脚本未经服务器执行，不能由“引用了官方文档”推断结果数值正确。
