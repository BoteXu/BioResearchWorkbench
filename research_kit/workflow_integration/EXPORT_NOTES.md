# Portable public source export

This directory contains the selected source, contracts, method reviews and configuration templates. Original attachments, local machine configuration, adoption transactions, historical execution receipts, caches, raw data and rendered-case data are intentionally not shipped. References to those materials in retained historical documents describe local evidence, not files delivered here. No automatic installation, adoption, server submission or private-data redistribution is authorized by this export.

Scientific/runtime acceptance is distinct from source review. Recheck actual server dependencies, model/license terms, inputs and fresh completion receipts before execution. Historical `SERVER_UNAVAILABLE` fields in immutable registries are historical only; no present server availability is asserted.
