# 本轮公开方法/API 核对来源（私有记录）

只检索公开方法/API 信息，未发送用户数据、序列、私有文稿、目录、主机、结果或日志。第三方算法经已有服务器环境调用，没有复制分发第三方权重、数据库或完整第三方源码；新增原生替代实现单独命名。

- GSVA 参数对象：[官方 vignette](https://bioconductor.org/packages/release/bioc/vignettes/GSVA/inst/doc/GSVA.html)。按当前 gsvaParam/ssgseaParam API 准备，不能沿用旧式直接参数调用。
- DRIMSeq：[官方手册](https://bioconductor.org/packages/release/bioc/manuals/DRIMSeq/man/DRIMSeq.pdf)；基因/特征检验、比例与过滤分开保留。
- decoupleR：[官方 ULM 文档](https://saezlab.github.io/decoupleR/reference/run_ulm.html)。活动为加权靶特征模式的估计，不是直接活性测量。
- CellRank：[官方 GPCCA API](https://cellrank.readthedocs.io/en/stable/api/_autosummary/estimators/cellrank.estimators.GPCCA.html)。终末状态与归一化概率需要真实诊断。
- scVelo：[官方动力学说明](https://scvelo.readthedocs.io/en/stable/DynamicalModeling.html)。恢复动力学在 dynamical velocity 之前。
- LIANA：[官方 rank aggregate API](https://liana.readthedocs.io/en/stable/generated/liana.mt.rank_aggregate.__call__.html)。采用显式本地资源并逐供者运行。
- cooltools：[官方 API](https://cooltools.readthedocs.io/en/stable/cooltools.html)。Python dots 的 FDR 参数是 lambda_bin_fdr，不能照抄 CLI 的 fdr 参数名。
- Scirpy：[官方 clonotypes 定义](https://scirpy.scverse.org/en/latest/generated/scirpy.tl.define_clonotypes.html)。严格 clonotype 使用核苷酸身份；不把 AA 聚类误标为该定义。
- PyClone-VI：[官方源码](https://github.com/Roth-Lab/pyclone-vi)。调用 fit/write-results-file；分开保留细胞比例、比例标准差和簇分配概率。外加的 sum-rule 候选树枚举是本包独立方法。
- CNVkit：[官方 pipeline](https://cnvkit.readthedocs.io/en/master/pipeline.html)。纯度/倍性网格是预设敏感性，不是自动得到的后验最优解。
- TOBIAS：[官方参数源码](https://github.com/loosolab/TOBIAS/blob/main/tobias/parsers.py)。使用 ScoreBigwig，明确 footprint 的 fp-min/fp-max，不能把仅用于 sum 的 window 当成足迹宽度。
- StrainPhlAn：[官方说明](https://github.com/biobakery/MetaPhlAn/wiki/StrainPhlAn-4)。本地 marker 与数据库，marker/sample 覆盖阈值用于实际敏感性。
- pySCENIC：[官方用法](https://pyscenic.readthedocs.io/en/latest/installation.html)。GRN→motif pruning→AUCell，已有本地数据库，保留完整中间结果。
- miloR：[官方 testNhoods](https://marionilab.github.io/miloR/reference/testNhoods.html)。设计与供者计数对应，SpatialFDR 与普通 FDR 分开。

以上为源码准备依据，不证明当前服务器已安装、API 实机兼容或科学结果有效。每项实际版本由真实运行回执记录。
