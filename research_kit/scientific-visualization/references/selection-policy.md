# Choose forms by the question and available channels

Do not spread one line-and-dot grammar across a whole report. A lollipop is
an optional compact ranking form, not a universal default. Preserve meaningful
CI forests and paired dumbbells: their lines encode uncertainty or a real pair,
not decorative stems. Retain old designs and compare on the same input.

| Available information / purpose | Preferred form | Optional alternatives / limits |
|---|---|---|
| Counts or actual observed fractions | Compact sorted bars with n and % | Stacks for composition, explicit donor facets when real donors exist |
| Ranked enrichment effect, FDR and set size | Stem-free evidence bubbles | NES when supplied, otherwise actual ratio; no invented contrasts |
| Additive signed energy components and total | Waterfall with additive-total guard | Original signed components or stacked balance when explicitly chosen |
| Effect with valid interval | Aligned CI forest with exact numeric column | Distribution forest only with real frozen density |
| Raw observations and distribution | Raincloud with actual points and IQR | Split violin for exactly two real categories, ridges for many groups |
| Stored embedding identities | Labeled atlas; profile adds counts | Per-identity highlight facets, no coordinate refit or decorative ellipses |
| Correlated multivariate values | Aligned heatmap, trees, strips and guides | Explicit condition blocks; same default distance/linkage |
| Sample PCA | Points, estimable dispersion ellipses and marginals | Exact matched-stage layouts, no separation test implied |
| Differential expression | Volcano and stacked marginal summaries | Real multi-contrast facets with shared scales and thresholds |
| GSEA | ES/hit/ranking tracks with full pathway statistics | Shared-axis overlay only for matching supplied rank channels |
| Marker characterization | Per-identity highlights plus multiple markers | Mean/fraction dot matrix and expression summaries; no scaled-value detection |
| SHAP sample variation and global magnitude | Swarms with a small calibrated rose inset, full feature denominator | Classic rose/ring companion, linear summary and large rose remain optional; actual output units and feature-color channel required |
| Time or spectral coordinate | Curves/sticks in physical coordinates | Clear stage facets, overview plus focused panel, no invented smoothing |
| 3D / trajectories / molecular fields | Genuine coordinate/field viewer | Static projections complement interaction; no substitute field |

Repeated heatmap families share one implementation with named variants; old
IDs continue to resolve. Different variants are not extra independent methods.
Report-level selection should cover complementary questions, not repeat the
same statistic in several shapes simply to make more figures. Single plots and
composites both need individual inspection at their actual physical size.


For tightly clustered near-ceiling performance scores, prefer an exact numeric
score matrix or the relevant ROC/PR/calibration panels. Radar and parallel
coordinates remain optional context views; they are not the default simply
because they are available. Keep the declared common scale and do not exaggerate
small differences by silently changing limits. An all-zero off-diagonal
interaction matrix is an explicit optional zero-result view, not a default
claim of informative interactions or zero main effects.

At 89 mm, CI forests use a complete numeric table below the effect panel by
default. Wider pages keep the side table; `layout="side"` and `layout="below"`
remain explicit alternatives. Never label an unspecified interval 95% CI.
Narrow heatmaps move condition/missing-value guides below the matrix and use
vertical sample labels when dense. Custom composites honor their actual total
width and refuse panels that require silent text shrinking.
