# v2.1 private workflow-review draft

The skill retains its original `scientific-visualization` name and identity,
140 unique figure identifiers, 22 figure-set modules, seven composite recipes,
16 palettes, original R/Python paths and qualified legacy-ID compatibility.
No saved skill is deleted, installed, published or frozen by this draft.

Changed result consumers and defaults:

- `shap_summary` uses the small rose inset within the sample swarm by default.
  Full-feature magnitudes and the explicit remainder keep the true denominator.
  Large roses, swarm/bar companions and legacy rose/ring forms stay optional.
- Output units and feature-color scales are explicit. Probability, decision
  scores, log-odds and regression-response units are not interchangeable.
- Generic ML views use supplied class order, partition and validation scope.
  A template does not invent disease labels, a threshold or five-fold OOF status.
- PCA and heatmaps reject incomplete group orders and mismatched identities.
  Frozen source linkages require exact axis IDs and retain their original
  method/distance. An object or latent matrix is not automatically UMAP.
- Narrow forests use a complete numeric table below the effect panel; narrow
  heatmaps put guides below. Actual panel width governs composite child layout.
- Native SHAP, numeric matrices, BATCHIE posterior intervals, ProteinTalks
  discrete checkpoints and stored-PCA handoffs have actual result-only readers
  and renderers. Unknown model/object formats require an upstream frozen export.

Read `references/workflow-results.md` and `assets/workflow_channels.json` before
consuming the private teaching workflow's results. All 49 added route roles have
semantic mappings; they do not represent 49 executed or scientifically accepted
engines. Real completion, exact source, returned QC and selected-file bindings
are required. Neither software tests nor example figures replace those gates.

The separate review delivery contains 35 static layouts and three real
composites, with exact-export visual records. Two Diabetes-derived style checks
have incomplete original-data license records and do not count as complete
real-case acceptance. The other 36 examples are delivered in the separate
private gallery. These targeted examples are not a new full-library 140-item
review. Original channel-limited states remain unresolved unless specifically
reassessed. Unchanged R alternatives, 3D and GIF methods were not newly rendered
in this update; R syntax checks are reported separately.

The original host-specific frontmatter fields remain intact. A minimal generic
Codex validator has a narrower schema and rejects those inherited fields. This
draft has not been migrated or installed as a generic Codex skill. Host identity,
imports and legacy compatibility are checked separately; no blanket portability
claim is made.
